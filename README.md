### About

Lead developer at [ShopHelten ApS](https://shophelten.dk), based in Denmark.
I build and maintain Shopify stores for brands and retailers: custom themes, store architecture,
integrations and the performance work that keeps it all fast.

### What I work on

- Custom Shopify themes on Online Store 2.0 (sections, theme blocks, metafields and metaobjects)
- Shopify Functions, checkout and customer account extensions
- Integrations via the Admin and Storefront GraphQL APIs (ERP, PIM, shipping, marketing tools)
- Performance and Core Web Vitals optimization
- Migrations to Shopify from WooCommerce, Magento and other platforms
